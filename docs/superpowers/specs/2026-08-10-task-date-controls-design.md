# 事项日期控件微调设计

## 目标

在不改变日期迁移规则的前提下，收紧事项日期编辑权限，并让日期入口、日期文本和后续筛选与现有界面视觉一致。

## 交互

- 未完成事项无日期时，在标题后紧邻显示无填充的 `CalendarDays` 线框图标。
- 未完成事项有日期时，在标题后显示 `M/D`；点击可打开原生日期选择能力，并提供清除日期操作。
- 已完成事项不显示日期编辑图标和清除按钮；已有日期仅以只读 `M/D` 展示，无日期不展示。
- 逾期标签始终只显示“已逾期”，不附带日期。
- 后续安排筛选触发器位于标题栏右上角，与“完成记录”采用同一文字按钮风格。
- 筛选触发器在当前选项后显示向下箭头，明确可展开。
- 筛选菜单采用现有操作菜单的浮层视觉，紧凑间距、最小宽度，当前选项显示勾选。
- “完成记录”入口始终显示下划线。
- 日期入口不显示独立清除按钮；点击图标或日期文字直接唤起日期选择器，不先切换成中间输入框。
- 点击菜单外部或按 Escape 关闭；选择后立即过滤并关闭。

## 实现边界

- 不新增组件库，复用 `lucide-react` 与现有菜单样式。
- 不修改后端、日期筛选规则、rollover 或数据结构。
- 同步维护主入口与相关静态契约测试。

## 验收

- 已完成事项无法修改或清除日期。
- 逾期标签不重复显示计划日期。
- 日期图标为单色线框并紧跟标题。
- 日期文本与“完成记录”按钮的颜色和字号一致。
- 后续筛选处于右上角且不是原生 `select`。
