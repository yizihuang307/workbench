# macOS 今日安排桌面挂件（简单版）

## 范围

- 仅支持 macOS。
- 挂件固定在桌面窗口层，不遮挡普通应用窗口。
- 无系统托盘、自动更新、开机启动和签名安装。
- 展示今日安排并支持勾选完成；其他操作进入完整工作台。

## Web 页面

- 新增受现有登录保护的 `/widget/today` 页面。
- 复用 `GET /api/tasks?area=today` 获取数据。
- 复用 `PATCH /api/tasks/:id` 和 `version` 乐观锁更新完成状态。
- 页面加载、重新获得焦点和手动刷新时同步数据。
- 使用半透明卡片、紧凑任务列表和“打开工作台”入口。

## macOS 容器

- 简单版使用系统现有 Swift/AppKit 工具链，避免额外安装 Rust。
- 使用 `WKWebView` 加载挂件页面。
- 窗口无边框、半透明、可拖动、可缩放并记忆位置。
- 窗口位于桌面层之上、普通应用窗口之下，并显示在所有桌面空间。
- 开发环境默认加载本地地址；可通过环境变量指定已部署站点地址。

## 验收

- 普通应用窗口能够覆盖挂件。
- 返回桌面后可见挂件。
- 今日任务与云端一致。
- 勾选任务后立即更新，冲突时重新加载并显示提示。
- 关闭并重新启动后恢复上次位置和尺寸。
