# macOS 今日安排桌面挂件（简单版）

## 范围

- 仅支持 macOS。
- 无系统托盘、自动更新、开机启动和签名安装。
- 展示今日安排并支持勾选完成；其他操作进入完整工作台。

## 入口

- 今日安排卡片右上角提供「便签模式」。
- 点击后唤起本机便签窗口，并同步当前登录会话与今日任务。
- 若本机便签尚未启动，先通过 `workbench-today://show` 拉起，再重试控制接口。

## Web 页面

- `/widget/today` 复用 `GET /api/tasks?area=today` 和 `PATCH /api/tasks/:id`。
- 接收原生容器注入的会话后加载任务。
- 便签右上角提供刷新、打开工作台和退出。

## macOS 容器

- 无边框半透明浮动窗口，可点选、拖动、缩放并记忆位置。
- 启动时置于前台，不锁死在桌面背景层。
- 本地控制服务 `127.0.0.1:17891` 负责显示和退出。
- 便签内「退出」关闭应用。

## 验收

- 从今日安排点击「便签模式」后，便签出现在前台并可点击。
- 已登录网页后，便签直接显示今日任务，无需再次登录。
- 勾选完成后与云端一致。
- 点击退出后便签关闭。
