# 今日事响应式高度设计

## 问题

- 桌面卡片固定为 `560px`，矮屏中标题区、卡片和页面间距叠加后超过视口，产生页面级纵向滚动。
- 页面最大宽度限制在约 `1200px`，大屏空间利用不足。
- 后续安排标题与右侧筛选控件缺少明确的伸缩边界，窄列中可能越界。

## 方案

- 宽屏桌面下，今日事页面占满一个视口并采用纵向 flex 布局。
- 标题区固定占用内容高度，安排看板弹性填充剩余空间。
- 两个安排卡片取消固定高度，随看板等高拉伸；事项过多时仅任务列表内部滚动。
- 页面最大内容宽度提升到 `1440px`，超宽屏仍保留合理留白。
- 后续安排标题区允许收缩和换行，右侧筛选保持固定宽度并贴齐右上角。
- 900px 以下继续使用现有单列自然滚动，640px 以下维持移动端布局。

## 验收

- 常见 1366×768 桌面视口不出现今日事页面级纵向滚动。
- 大屏下看板宽高随可用空间增长，不出现大面积无意义留白。
- 今日安排和后续安排标题、统计和右侧操作对齐一致。
- 后续筛选不越出卡片边界。
- 任务过多时仅卡片内部列表滚动。
