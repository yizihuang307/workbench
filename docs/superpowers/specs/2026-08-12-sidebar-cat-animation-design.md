# 侧栏猫猫动效设计

## 目标

在桌面端左侧导航栏底部空白区域展示猫猫动效，为工作台增加轻量陪伴感。默认展示爱心猫，用户点击猫猫后按固定顺序切换三种动画。

## 交互规则

- 默认动画：`Cat feeling love emotionsexpression`。
- 切换顺序：爱心猫 → 大笑猫 → 哭泣猫 → 爱心猫。
- 当前动画持续循环播放。
- 点击后立即切换到下一只，并从第一帧开始循环播放。
- 点击区域使用按钮语义，提供对应的无障碍名称和轻微按压反馈。
- 不持久化选择；刷新页面后恢复爱心猫。

## 布局与响应式

- 新增独立 `SidebarCat` 客户端组件，放在主导航之后、侧栏底部。
- 桌面端使用侧栏剩余空间将猫猫靠下、水平居中展示，不覆盖导航和账户菜单。
- 动效尺寸适配当前 188px 宽侧栏，并保留安全内边距。
- 在侧栏收窄布局及移动端底部导航中隐藏，避免挤压导航项。

## 动画资源与实现

- 将三份 `.lottie` 文件中的动画 JSON 解包到 `public/cats/`，使用语义化文件名：
  - `love.json`
  - `laugh.json`
  - `cry.json`
- 复用项目现有 `lottie-web`，不新增运行时依赖。
- 动态导入播放器，避免进入服务端渲染路径。
- 每次切换先销毁旧实例，再创建并循环播放新动画；组件卸载时同步清理实例。
- 加载失败时保留按钮占位，不影响侧栏导航。
- 用户启用 `prefers-reduced-motion: reduce` 时不自动播放，仅渲染静态首帧；点击仍可切换。

## 验证

- 默认加载爱心猫并持续循环。
- 连续点击可按固定顺序轮换，第四次回到爱心猫。
- 切换不会叠加多个动画实例。
- 桌面端位置与红框区域一致，缩窄侧栏及移动端不展示。
- 动效不阻塞导航、账户菜单或页面内容交互。
- TypeScript、ESLint 和相关渲染回归测试通过。
