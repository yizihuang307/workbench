# 个人工作台交互文档 interaction.md

> 对齐：`docs/idea.md` @ 2026-08-02
> 本轮范围：信息模块资料详情编辑器；其他页面沿用现状。

## 1. 目标与原则

资料详情是一张连续文档，不是“文字／链接／文件”三种工具的集合。打开后立即可输入；粘贴网址自动链接；文件和图片可拖到光标所在位置。用户无需先理解内容类型。

## 2. 页面规格

| 字段 | 内容 |
|---|---|
| 页面 ID | `information-resource-editor` |
| 呈现 | 信息模块内固定大工作区，不新增独立页面或弹窗 |
| 入口 | 点击资料行，或点击分区新增 |
| 出口 | 返回总览、关闭或切换模块 |
| 桌面 | 左侧资料列表＋右侧大编辑区 |
| 手机 | 编辑区占满正文，返回后回到原列表位置 |

### 布局

1. 顶部工具行：返回、所属分区(仅展示，不支持下拉修改）、保存状态、删除(弹窗二次确认）关闭。
2. 标题：单行输入；默认取正文完整首行，手动修改后停止自动覆盖。
3. 文档编辑区：唯一主要输入区域，占满剩余空间。
4. 空状态提示：“输入文字，或粘贴链接、拖入文件”。
5. 删除常驻的“＋文字／＋链接／＋文件”按钮。
6. 光标位于正文时显示轻量格式栏；它只提供便签常用格式，不扩展成完整办公软件工具栏。

### 页面状态

| 状态 | 呈现与恢复 |
|---|---|
| loading | 编辑区骨架，加载完成后焦点进入正文 |
| empty | 显示弱提示，可直接输入、粘贴或拖放 |
| error | 显示错误说明和返回总览，不覆盖原数据 |
| saving | 顶部显示“保存中”，不阻断输入 |
| saved | 顶部显示“已保存” |
| save-error | 保留当前内容，顶部显示失败并用 toast 说明 |

## 3. 顶部工具行

- `information-resource-editor-E-A-01` 返回总览：返回信息首页【呈现方式：`navigate`】，保留首页滚动位置。
- `information-resource-editor-E-A-02` 所属分区：点击选择分区【呈现方式：`popover`】，选择后立即移动并 toast 提示。
- `information-resource-editor-E-A-03` 保存状态：只读显示保存中、已保存、保存失败。
- `information-resource-editor-E-A-04` 更多操作：【呈现方式：`popover`】，仅保留删除；二次弹窗确认。
- `information-resource-editor-E-A-05` 关闭：返回信息首页，焦点回到此前资料行。

## 4. 标题

- `information-resource-editor-E-B-01` 标题输入框【呈现方式：`inline-edit`】。
- 新资料默认“未命名资料”；输入正文后自动取完整首行，最多 200 字。
- 用户手动修改标题后，正文变化不再覆盖标题。
- 标题为空或纯空格时，失焦后恢复正文首行；正文也为空则恢复“未命名资料”。

## 5. 统一文档编辑区

### 轻量格式栏

桌面端格式栏固定在编辑区顶部、标题下方；手机端显示在键盘上方，可横向滑动。没有进入正文编辑时保持隐藏或弱化。

| 控件 | 能力 | 行为 |
|---|---|---|
| `Aa` | 正文、标题、小标题 | 对当前段落生效；不改变整篇资料标题 |
| `B` | 粗体 | 对选中文字或后续输入生效 |
| `I` | 斜体 | 对选中文字或后续输入生效 |
| 列表 | 项目符号、编号、核对清单 | 点击后用紧凑 `popover` 选择一种列表 |
| 表格 | 插入简单表格 | 在光标处插入默认 `2×2` 表格 |
| 附件 | 选择图片或文件 | 在当前光标位置插入所选附件 |
| 撤销/重做 | 撤销、重做 | 桌面主要使用快捷键；手机端保留两个按钮 |

- 格式栏不提供字体、字号、文字颜色、段落间距、对齐、合并单元格和复杂样式。
- 输入 `# `、`## `、`- `、`1. `、`[] ` 后按空格，可分别转换为标题、小标题、项目符号、编号和核对清单。
- `Cmd/Ctrl+B` 和 `Cmd/Ctrl+I` 分别切换粗体、斜体。
- 桌面端和手机端都在格式栏末尾保留一个紧凑的附件入口。桌面端同时支持拖放和文件选择；手机端主要使用文件选择。

### 表格

- 点击表格按钮后，在光标位置插入 `2×2` 表格，焦点进入第一个单元格。
- `Tab` 移到下一个单元格；在最后一个单元格按 `Tab` 自动新增一行；`Shift+Tab` 返回上一个单元格。
- 选中表格时显示紧凑的上下文菜单，可在当前行或列前后新增、删除当前行、删除当前列和删除表格。【呈现方式：`popover`】
- 手机端点击单元格进入编辑；表格宽于屏幕时仅表格内部横向滚动，页面本身不横向滚动。
- 首期不支持合并单元格、计算公式、单元格颜色、固定表头和复杂尺寸调整。

### 文字

- 点击任意空白处即可定位光标并输入，不需要先创建文字块。
- 支持换行、选择、复制、剪切、粘贴、`Cmd/Ctrl+Z` 撤销和 `Cmd/Ctrl+Shift+Z` 重做。

### 链接

- 输入或粘贴 `http/https` 地址后，在空格、换行或失焦时自动变成蓝色下划线链接。
- 编辑状态下普通点击只定位光标；`Cmd/Ctrl+点击` 在新标签打开【呈现方式：`newtab`】，避免误跳转。
- 选中文字后粘贴网址，将所选文字直接转为链接。
- 单独占一行的网址仍显示普通文字链接，不自动生成大卡片。
- `javascript:`、`data:` 等危险协议保持普通文本。

### 文件和图片

- 文件或图片拖入编辑区时，正文中出现蓝色插入线；松手后插入该位置。
- 点击附件按钮后打开系统文件选择器；选择完成后插入当前光标位置。如果编辑区尚无光标，则插入文档末尾。
- 拖放和文件选择使用同一套文件类型、单文件容量、总容量、保存和错误处理规则。
- 支持一次拖入多个文件，按选择顺序插入。
- 图片粘贴到光标位置并直接显示；普通文件显示紧凑附件行：文件名、类型、大小、下载。
- 选中图片或附件后按 `Delete/Backspace` 删除，不显示常驻红色删除按钮。
- 点击图片打开大图【呈现方式：`modal`】；`Esc`、遮罩、关闭按钮均可退出，焦点返回图片。
- 桌面可拖动图片或附件到其他段落之间；手机长按后提供上移/下移替代操作。

## 6. 保存与退出

- 输入后短暂延迟自动保存；连续输入只保存最后状态，不移动光标。
- 切换资料前提交待保存状态；失败时保留内存内容，不静默覆盖。
- 重新打开后恢复正文、链接、图片、附件顺序、标题和分区。
- 多标签页修改同一资料时不自动覆盖当前编辑，提示刷新确认。

## 7. 边界与异常

| 场景 | 规则 |
|---|---|
| 空内容 | 允许保存，标题为“未命名资料” |
| 30000 字 | 停止继续输入并提示，不截断已有内容 |
| 超长链接 | 自动换行，不撑破编辑区 |
| 离线 | 本地编辑保存不受影响，不请求链接预览 |
| 重复文件 | 允许插入，由用户决定删除 |
| 单文件失败 | 只提示该文件，不撤销同批其他文件 |
| 撤销 | 文字、链接化、插入、删除和移动进入同一撤销历史 |
| XSS | 文字按文本保存渲染，禁止执行粘贴 HTML 脚本 |

## 8. 数据需求

- 读：标题、分区、连续文档内容、更新时间。
- 写：标题及自动标题状态；文字与链接标记；图片、附件及顺序；所属分区；删除和 5 秒撤销快照。
- 写入失败时保留当前编辑状态并提示，不清空用户内容。

## 9. 验收标准

1. 新建资料无需点击内容类型按钮即可输入。
2. 粘贴网址自动成为蓝色下划线安全链接。
3. 选中文字粘贴网址后，文字成为链接。
4. 文件可拖到任意段落之间，刷新后顺序不变。
5. 图片可粘贴、放大、键盘删除并撤销。
6. 整个详情页只有一个主要编辑面。
7. 保存、失败、撤销、关闭和多标签页冲突均有明确结果。
8. 标题、小标题、粗体、斜体、项目符号、编号、核对清单和简单表格均可通过格式栏完成。
9. 手机端格式栏不遮挡正文和系统键盘，表格不会撑破页面。
10. 桌面端可通过拖放或附件按钮插入同一文件，两种入口的结果一致。
