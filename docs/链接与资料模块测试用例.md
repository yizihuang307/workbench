# 【链接／资料】模块测试用例

> 范围：链接库、链接分组、资料分类看板、现有资料详情编辑器、本地持久化与响应式交互。
> 原则：核心数据操作先做规则测试，再做页面结构测试，最后做真实浏览器关键链路回归。

## P0：核心数据完整性

| 编号 | 场景 | 预期 |
|---|---|---|
| P0-01 | 新增有效链接 | 自动补全协议、识别名称和 Logo，失败时使用域名与 favicon 后备 |
| P0-02 | 空网址、非法协议、脚本网址 | 禁止保存且不执行任何内容 |
| P0-03 | 重复网址 | 明确提示；用户确认后才允许同网址重复保存 |
| P0-04 | 编辑链接名称和网址 | 两者同时保存；非法值不覆盖原数据 |
| P0-05 | 删除链接 | 只删除目标项，不影响其他分组和顺序 |
| P0-06 | 新增、重命名链接分组 | 去首尾空格、限制 40 字、禁止空名和重名 |
| P0-07 | 删除有内容的链接分组 | 内容迁移到“未分组”，无数据丢失 |
| P0-08 | 链接组内排序与跨组移动 | 目标组、目标位置和各组 order 正确，刷新后保持 |
| P0-09 | 新增资料分类 | 固定列头新增入口；空名、重名不可保存 |
| P0-10 | 手动拖动资料分类 | 首列、末列、相邻及跨多列排序正确，order 连续 |
| P0-11 | 分类改用名称／更新时间排序 | 禁止手动拖拽，避免视觉顺序与保存顺序不一致 |
| P0-12 | 分类内资料排序 | 顶部、中间、底部放置正确；未移动其他分类 |
| P0-13 | 资料跨分类移动 | 原分类移除、目标分类准确插入、两侧 order 连续 |
| P0-14 | 拖入空分类 | 资料成为目标分类第一项 |
| P0-15 | 无效落点或按 Esc 取消 | 数据保持原样，不产生重复资料 |
| P0-16 | 删除资料分类 | 内容迁移到明确目标分类；最后一个分类不可删除 |
| P0-17 | 新增、编辑、删除资料 | 自动保存；删除提供 5 秒撤销；空草稿退出后清理 |
| P0-18 | 刷新、关闭重开 | 分类顺序、资料归属、资料顺序、链接分组和偏好恢复 |
| P0-19 | 保存失败 | 显示错误，不伪装成“已保存”，当前内存内容保留 |
| P0-20 | 旧版或损坏数据 | 可迁移数据保留；非法字段丢弃；页面不崩溃 |

## P1：搜索、排序与视图

| 编号 | 场景 | 预期 |
|---|---|---|
| P1-01 | 搜索链接名称、完整网址、域名 | 大小写不敏感，命中词高亮 |
| P1-02 | 搜索资料标题、正文、链接和文件名 | 统一结果列表，命中词高亮 |
| P1-03 | 特殊正则字符 `[]()*+?` | 按普通文字搜索，不抛异常 |
| P1-04 | 前后空格、中文、英文、日韩文、Emoji | 正常搜索，不破坏文本 |
| P1-05 | 无结果 | 保留搜索框与清除能力，显示明确空态 |
| P1-06 | 清空资料搜索 | 恢复看板和此前横向、列内滚动位置 |
| P1-07 | 链接手动／名称／最近打开排序 | 结果稳定；非手动模式禁用拖拽 |
| P1-08 | 资料手动／名称／更新时间排序 | 置顶规则一致；非手动模式禁用拖拽 |
| P1-09 | 链接列表／网格切换 | 数据和筛选不变，刷新后恢复偏好 |
| P1-10 | 1000 条资料和 1000 条链接 | 无丢失、可搜索、排序结果稳定 |

## P1：资料详情与附件回归

| 编号 | 场景 | 预期 |
|---|---|---|
| P1-11 | 空资料、纯空格、超长标题和正文 | 空草稿按规则清理；标题 200 字、正文 30000 字边界生效 |
| P1-12 | 粘贴网址与选中文字加链接 | 只允许 http/https，安全属性完整 |
| P1-13 | HTML／脚本注入 | 脚本、事件属性和危险协议被移除 |
| P1-14 | 图片粘贴、拖入、放大、调整大小、键盘删除 | 顺序与正文一致，撤销／重做有效 |
| P1-15 | 普通文件上传与下载 | 文件名、类型、大小和内容保持 |
| P1-16 | 单文件超过 20MB | 拒绝并说明原因 |
| P1-17 | 单资料超过 20 个附件 | 拒绝超出部分，不损坏已有附件 |
| P1-18 | 资料库附件累计超过 200MB | 阻止继续添加或安全恢复，不让存储崩溃 |
| P1-19 | 切换分类后保存 | 归属更新，返回看板出现在正确列 |
| P1-20 | Ctrl／Command+Z、重做 | 文字、格式、链接、图片和附件进入同一历史 |

## P1：交互与响应式

| 编号 | 场景 | 预期 |
|---|---|---|
| P1-21 | 点击空白处、Esc、打开新菜单 | 旧菜单或弹层关闭，焦点返回触发按钮 |
| P1-22 | 分类很多 | 看板横向滚动，固定列宽，不压缩成不可读窄列 |
| P1-23 | 单列内容很多 | 只滚动列体，列头和新增按钮固定可见 |
| P1-24 | 拖动到横向或纵向视口边缘 | 自动滚动，拖动层不被相邻容器遮挡 |
| P1-25 | 手机端 | 使用菜单完成移动和排序，不把拖拽作为唯一能力 |
| P1-26 | 320px、平板、桌面、200% 缩放 | 无横向页面溢出；看板自身可横向滚动；核心操作可达 |
| P1-27 | 键盘操作 | 搜索、菜单、新增、编辑、关闭均可完成且焦点可见 |
| P1-28 | 减少动画 | 取消拖拽位移动画，不影响结果反馈 |

## P2：并发和异常

| 编号 | 场景 | 预期 |
|---|---|---|
| P2-01 | 快速重复新增、删除、拖放 | 操作幂等，不出现重复 ID 或幽灵项 |
| P2-02 | 拖动过程中目标被删除 | 取消移动并保持可恢复数据 |
| P2-03 | 多标签页同时修改 | 提示存在外部修改，不静默覆盖当前编辑 |
| P2-04 | IndexedDB 不可用、容量不足 | 页面仍可查看当前数据，明确提示无法持久化 |
| P2-05 | Logo／元数据接口失败、超时、跨域失败 | 使用域名和 favicon 后备，不阻断新增 |
| P2-06 | 超长名称、无断点网址、RTL 文本 | 不挤压操作按钮，全文可查看 |
| P2-07 | 重复 order、负数、NaN、孤儿分类 ID | 解析时归一化，顺序稳定，孤儿资料迁入有效分类 |
| P2-08 | 页面切换和详情返回 | 搜索、筛选、排序、横向及列内滚动位置保持 |

## 发布门槛

- P0 全部通过；P1 不得存在阻断核心链路的问题。
- 单元测试、页面结构测试、完整构建全部通过。
- 手工验证桌面与手机核心链路：新增、搜索、编辑、排序、跨组移动、删除、撤销、刷新恢复。
- 资料详情页已有编辑能力不得回归。
