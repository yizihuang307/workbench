# 个人工作台：产品方案与模块边界

## 一、产品定位

个人工作台用于集中处理个人每天高频使用的安排、记录、信息和心情数据。产品强调快速进入、低干扰、数据稳定和本地优先，不提前加入没有明确价值的复杂配置。

## 二、模块规划

### 1. 安排

- 分为今日、本周和后续三个区域。
- 支持新增、完成、恢复、删除、撤销、拖拽排序、跨区域移动、P0 和隐藏已完成。
- 今日未完成事项跨日保留并标记遗留。
- 快速记录入口位于首页。

### 2. 记录

- 默认分类为“随手记”和“会议纪要”，它们只是可编辑、可删除的分类名称，不是固定模板。
- 用户可以新增、编辑和删除分类。
- 记录不强制填写标题，列表标题默认取正文第一行，并随首行输入完整更新；用户手动修改标题后不再自动覆盖。
- 快速记录可选择保存分类，并可将某个分类设为默认分类；默认分类设置只放在首页快速记录区域。
- 编辑体验接近文档：正文与图片属于同一个内容流，支持撤销、图片粘贴、插入位置调整、键盘删除和图片放大。
- 列表支持搜索并高亮关键词、置顶、移动分类和删除。
- AI 整理按单条记录独立运行；处理完成后可选择替换当前内容、同时保留原文和结果，或取消。

### 3. 信息

- 预置分区：常用链接、工作资料、学习收藏。
- 支持网页链接、本地文件和文字资料。
- 常用链接只需输入网址，系统自动识别网页名称和 Logo；识别失败时使用域名和首字母作为后备。
- 常用链接支持编辑名称、重新识别和删除。
- 资料标题默认取正文完整首行，允许手动修改。
- 分区首页使用紧凑列表展示，超过五项可“查看全部”并在当前页面展开，不进入独立页面。
- 资料编辑采用固定在页面中的大面积工作区，不使用容易误触的大弹窗，也不使用面积过小的右侧抽屉。
- 文件数据使用 IndexedDB 保存，避免 localStorage 容量不足。
- 资料详情使用统一文档编辑器，不再让用户分别选择“文字／链接／文件”内容块。
- 直接输入即创建正文；网址自动识别为蓝色下划线链接；选中文字后粘贴网址可为文字添加链接。
- 文件和图片可直接拖入正文指定位置或粘贴进入，成为连续文档的一部分。

### 4. 心情

- 随时选择表情记录当前心情。
- 后续支持时间轴和趋势查看。
- 本模块尚未进入详细设计和开发。

## 三、当前交付边界

- 当前版本为本地优先的个人版。
- 安排、记录和信息模块已有可运行实现。
- 心情模块仅保留入口和方向，尚未冻结功能边界。
- 暂不宣称支持账号、跨设备同步、多用户协作和正式权限体系。
