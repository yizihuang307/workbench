# 个人工作台：产品方案与模块边界

## 一、产品定位

个人工作台用于集中处理个人每天高频使用的安排、记录、信息和心情数据。产品强调快速进入、低干扰、数据稳定和本地优先，不提前加入没有明确价值的复杂配置。

## 二、模块规划

### 1. 今日事（安排域）

- 分为今日、本周和后续三个区域。
- 支持新增、完成、恢复、删除、撤销、拖拽排序、跨区域移动、P0 和隐藏已完成。
- 今日未完成事项跨日保留并标记遗留。
- 快速记录入口位于首页。

### 2. 随手记（记录域）

- 默认分类为“随手记”和“会议纪要”，它们只是可编辑、可删除的分类名称，不是固定模板。
- 用户可以新增、编辑和删除分类。
- 记录不强制填写标题，列表标题默认取正文第一行，并随首行输入完整更新；用户手动修改标题后不再自动覆盖。
- 快速记录可选择保存分类，并可将某个分类设为默认分类；默认分类设置只放在首页快速记录区域。
- 编辑体验接近文档：正文与图片属于同一个内容流，支持撤销、图片粘贴、插入位置调整、键盘删除和图片放大。
- 列表支持搜索并高亮关键词、置顶、移动分类和删除。
- AI 整理按单条记录独立运行；处理完成后可选择替换当前内容、同时保留原文和结果，或取消。

### 3. 传送门（链接域）

- 从原【信息】模块拆出，成为独立导航目录。
- 默认分组为“全部”和“未分组”，支持新增、重命名、删除和手动排序分组。
- 链接支持在组内排序、跨组移动、编辑名称与网址、删除和搜索。
- 新增时输入网址，系统自动识别名称和 Logo；名称可在保存前修改，识别失败使用域名和稳定图标后备。
- 支持紧凑列表与图标网格两种展示形式，并记住用户最后选择。
- 支持手动、最近打开、最近添加和名称排序；打开外部链接不离开工作台。

### 4. 资料库（资料域）

- 从原【信息】模块拆出，成为独立导航目录。
- 预置“工作资料”和“学习收藏”，支持新增、重命名、删除和排序分类。
- 桌面端使用横向分区看板：分类为固定宽度竖列，资料在列内纵向排列；页面左右滑动查看分类，每列内部独立滚动。
- 每列新增按钮固定在列标题栏，不放在列表底部；列级排序入口使用轻量文字/图标菜单，不使用紫色实底主按钮。
- 支持资料在列内排序、跨列移动、置顶、搜索和按更新时间／名称排序；搜索结果切换为统一列表，不保留空看板列。
- 手机端保留固定宽度横向看板，通过左右滑动查看分类；拖拽排序提供上下移动和分类选择替代。
- 资料标题默认取正文完整首行，允许手动修改；点击卡片进入现有统一文档编辑详情，不改变详情页交互。
- 文件数据使用 IndexedDB 保存，避免 localStorage 容量不足。
- 详情编辑器支持连续正文、自动链接、图片与文件插入、便签级格式和简单表格，不扩展为完整办公软件工具栏。

### 5. 心情（暂不开发并隐藏入口）

- 本模块尚未进入详细设计和开发。
- 桌面端和手机端导航入口均隐藏，不显示占位或“即将开放”。

## 三、当前交付边界

- 当前版本为本地优先的个人版。
- 【今日事】、【随手记】、【传送门】和【资料库】已有可运行实现；资料详情编辑器保持原有交互。
- 心情模块不在当前交付范围，导航入口隐藏。
- 暂不宣称支持账号、跨设备同步、多用户协作和正式权限体系。
